# MEDTRACK user guide

## 1. First run
1. Open the app. Read the privacy summary, then tap **Get started**.
2. Choose your usual playback speed and the daily hours you can realistically study. Tick weekly off days if you have any.
3. Enter NEET PG and INI-CET dates if they're known. Both are optional and can be changed later.
4. Tap **Preview bundled catalogue**. Check the counts, the per-subject table and the warnings (7 duplicate Biochemistry MCQ-discussion rows, 9 repaired long titles), tick "I reviewed the warnings", then **Import 1733 records**.
5. Allow notifications if you want reminders.

## 2. Daily use
- **Home:** countdowns, today's tasks, progress, debt, revisions, readiness. Show, hide or reorder cards in Settings → Dashboard.
- Tap the circle next to a task or lecture to mark it complete, and tap again to undo. The time and speed of completion are recorded.
- Use the **timer** (clock icon) while studying, or add minutes on a lecture's page. Actual time is tracked separately: ticking a task complete doesn't add study time.
- **MCQs → Log session** after each QBank block. Attempted must equal correct + incorrect, and skipped questions don't count as attempted.
- **Revision** (circular-arrows icon): on a lecture's page, tap **Add to revision plan**, then complete each due cycle with a confidence rating.
- **⋯ → Daily audit** in the evening: planned vs done, actual time, missed tasks, tomorrow's priorities.

## 3. Plans and adjusting the schedule
- **Schedule → Create a study plan:** choose content types, subjects and priorities (1 = first), daily minutes, maximum minutes, optional target date and mode, then **Preview schedule** and **Create plan**.
- **Pin** a task (pin icon) so it's never moved automatically. **⋯** on a task lets you move it to another date (marks it as manually edited), skip it, or remove it from the plan.
- With overdue tasks, tap **Recovery plan**, review the preview, then **Apply suggested changes** or **Keep my schedule**.
- After changing speeds or daily hours, use Recovery plan or **Plans → Duplicate / regenerate** to re-plan. Old plans are kept.

## 4. Speeds
Precedence: per-lecture override → subject default → global default. On a subject page, select lectures and tap **Speed…** to bulk-change. "Keep lectures that already have their own speed override" protects your individual choices. **Analytics → What-if speed simulator** compares all five speeds.

## 5. Notifications
Settings → Notifications: toggle each reminder, set times, days, quiet hours, sound and vibration, and a daily limit (extra reminders are combined). Browsers deliver reminders only while MEDTRACK is open or installed and running. If it was closed, you get one catch-up reminder when you next open it.

## 6. Backup & restore
⋯ → **Backup & restore**. Set a passphrase, then **Download encrypted backup** (works offline) or connect Google Drive and tap **Back up now**. To restore, pick a file or a Drive backup, enter the passphrase, check the preview, then choose Merge, Replace or Save as copy. Back up regularly: clearing your browser's site data erases the local database.

## 7. Re-importing a new catalogue version
Settings → Data → **Import / re-import catalogue**. Matching records keep their progress. Edited records carry their progress over. Records missing from the new file are only archived if you tick the box.

## 8. Resetting
Settings → Data: **Restore default settings** (progress untouched), **Reset progress**, or **Delete all data**. Remote Drive backups aren't deleted by any of these.
